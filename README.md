# Full-Stack Cohort

A project-based full-stack cohort for complete beginners. We learn each idea when the Poll Maker project needs it and use it immediately.

## Current project: Poll Maker

Sprint 1 is an individual build of a single-poll voting app: view options, vote, add and delete options, and see results. It connects a browser interface to an Express server and a MySQL database.
