# Sprint 1 Team Roles

Sprint 1 is individual-only: every student builds their own complete Poll Maker app. You are both a builder of your own work and a reviewer of a teammate's work.

## Builder

Follow [task-list.md](task-list.md), keep one task per commit, and be ready to explain what each part of your code does. Ask for help with the smallest clear description of the symptom and what you already tried.

## Reviewer

Review at least one teammate pull request each week. Check three things:

1. **Does it run?** Follow the stated check steps; report exactly what happens.
2. **Does it meet the task requirement?** Compare the change to its task ID, not to a feature from a later stage.
3. **Can the student explain their own code?** Ask a kind, specific question such as “What response does this route send when the option is missing?”

Leave concrete comments: identify the file or behavior, explain the observation, and suggest the next check. See [CONTRIBUTING.md](../CONTRIBUTING.md).
