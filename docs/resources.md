# Sprint 1 Resources

Use these when you reach the matching stage in [task-list.md](task-list.md). Prefer reading only what the immediate task needs.

| Build stage | Suggested free resource |
| --- | --- |
| Stage 0: web and Git | Search MDN for “how the web works” and GitHub Docs for “fork a repo” and “creating a pull request.” |
| Stage 1: page and browser code | MDN: HTML basics, CSS first steps, JavaScript arrays/functions, and “Introduction to the DOM.” |
| Stage 2: Node and Express | Node.js official Learn pages for npm and `package.json`; Express official “Getting started” and routing guide. |
| Stage 3: MySQL and SELECT | MySQL Reference Manual pages for `CREATE TABLE` and `SELECT`; mysql2 GitHub README examples for connecting from Node. |
| Stage 4: voting | MySQL Reference Manual for `UPDATE`; MDN `fetch()` and using request methods. |
| Stage 5: options | MySQL Reference Manual for `INSERT`, `DELETE`, and `SELECT`; MDN forms and `submit` events. |
| Stage 6: presentation | MDN CSS `width`; MDN `Array.reduce()` for summing votes; MySQL `ORDER BY`. |
| Stage 7: browser vote flag | MDN `Window.localStorage`; read its limits carefully before describing it as a security feature. |
| Stage 8: auto-refresh | MDN `setInterval()` and `fetch()`. |
| Stage 9: finish | MDN `try...catch` and Fetch API error handling; GitHub Docs “pushing commits.” |

If a search result is unfamiliar, choose the official MDN, Node.js, Express, MySQL, GitHub, or package project page rather than a random tutorial.
