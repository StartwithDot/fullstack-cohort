# Start Here

Welcome to the Poll Maker cohort repository. Sprint 1 is an individual project: build a voting app from browser page through Express server to MySQL database.

Read in this order:

1. [student-guide.md](student-guide.md) — make your copy and learn the Git mechanics.
2. [project-brief.md](project-brief.md) — agree on what Poll Maker includes.
3. [tools-setup.md](tools-setup.md) — install and verify the tools before Day 1.

Then use [sprint-map.md](sprint-map.md) for the big picture and [task-list.md](task-list.md) for the build. See [glossary.md](glossary.md) for new words and [troubleshooting.md](troubleshooting.md) when stuck.
